Estudio inicial previo a la realización del proyecto

1.1.Clasificar las empresas del sector por sus características organizativas y el tipo de producto o servicio que ofrecen
El proyecto se enmarca dentro del sector del comercio electrónico (e-commerce), concretamente en la venta online de productos textiles y moda urbana.
Las empresas del sector pueden clasificarse según:
Según su modelo de negocio:
B2C (Business to Consumer): Empresas que venden directamente al consumidor final.
B2B (Business to Business): Venta entre empresas.
C2C (Consumer to Consumer): Intercambio entre particulares.
BLÜK se clasifica como empresa B2C.
Según su estructura organizativa:
Microempresa (menos de 10 trabajadores).
Pequeña empresa (menos de 50 trabajadores).
Mediana empresa.
Gran empresa.
BLÜK se considera una microempresa de nueva creación, gestionada inicialmente por un pequeño grupo de socios.
Según el tipo de producto:
Productos físicos.
Productos digitales.
Servicios.
BLÜK comercializa productos físicos (ropa urbana estilo surfer y skater).




1.2. Poner un ejemplo de estructura organizativa para una empresa del sector
Dirección general: Toma de decisiones estratégicas.
Departamento de marketing y redes sociales: Promoción y posicionamiento de marca.
Departamento de ventas online: Gestión de pedidos y atención al cliente.
Departamento técnico: Mantenimiento de la plataforma web.
Logística: Gestión de stock y envíos.
En una fase inicial, varias de estas funciones pueden ser asumidas por los propios socios fundadores.

1.3. Identificar las necesidades demandas que cubre el proyecto y asociarlas con las necesidades del cliente.
El proyecto cubre las siguientes necesidades:
Digitalización del negocio: La marca actualmente no dispone de presencia online.
Canal de venta 24/7: Permite comprar sin limitación horaria.
Alcance geográfico ampliado: Venta a nivel nacional sin necesidad de tienda física.
Gestión automatizada de pedidos y stock.
Necesidades del cliente final:
Facilidad de uso.
Acceso desde cualquier dispositivo.
Proceso de compra sencillo y seguro.
Información clara del producto.

1.4. Descripción del proyecto.
El proyecto consiste en el desarrollo de una aplicación web de comercio electrónico denominada “BLÜK”, destinada a la venta online de ropa urbana.
La aplicación permitirá:
Registro e inicio de sesión de usuarios.
Gestión de perfiles.
Consulta de detalle de producto.
Añadir productos al carrito.
Gestión de pedidos.
Panel de administración con CRUD de productos.
Gestión de stock.
El sistema se desarrollará utilizando Laravel 11 bajo arquitectura MVC y se desplegará mediante contenedores Docker para facilitar su portabilidad y escalabilidad.
1.5. Justificar el tipo de proyecto elegido para dar solución al problema.
Se ha elegido el desarrollo de una aplicación web de comercio electrónico por los siguientes motivos:
El comercio electrónico es uno de los sectores con mayor crecimiento.
Permite aplicar de forma integral los conocimientos adquiridos en el ciclo DAW:
Programación backend.
Desarrollo frontend.
Bases de datos.
Seguridad.
Despliegue con contenedores.
Responde a una necesidad real de una marca existente.
Permite implementar buenas prácticas profesionales (Docker, control de versiones, arquitectura MVC).
Por tanto, es un proyecto completo, realista y alineado con el perfil profesional del ciclo.

1.6. Características principales del proyecto elegido.
Arquitectura MVC.
Desarrollo con Laravel 11.
Base de datos relacional MySQL/MariaDB.
Sistema de autenticación con roles (cliente/administrador).
Diseño responsive.
Despliegue mediante Docker.
Seguridad integrada (hash de contraseñas, CSRF, validaciones).
Escalabilidad futura.

2.4. Modelo de solución

2.4.1 Modelado de la solución

1. Texto: Descripción de la solución
La solución consiste en el desarrollo de una aplicación web de comercio electrónico denominada BLÜK, implementada mediante el framework Laravel 11 bajo arquitectura MVC (Modelo-Vista-Controlador).
La aplicación se ejecutará en un entorno contenerizado mediante Docker, permitiendo:
Portabilidad.
Escalabilidad futura.
Separación de servicios.
Despliegue sencillo en entorno local o VPS.
Arquitectura lógica
Modelo: Gestión de base de datos mediante Eloquent ORM.Vista: Blade + Tailwind CSS.Controlador: Gestión de peticiones HTTP y lógica de negocio.
Arquitectura física (contenedores)
Contenedor 1: Aplicación Laravel (PHP-FPM).
Contenedor 2: Servidor Web Nginx.
Contenedor 3: Base de Datos MySQL.
Contenedor 4 (opcional): Servicio de correo.
Contenedor 5 (opcional): Servicio de pago externo (Stripe API).
