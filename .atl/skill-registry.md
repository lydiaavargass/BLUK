## Project Conventions
- Follow conventions in [CONTRIBUTING.md](file:///C:/Users/Xavi/bluk/CONTRIBUTING.md)
- Commit messages in Spanish, prefixed with conventional commit types (e.g., `feat:`, `fix:`, `style:`, `docs:`, `refactor:`, `config:`)
- **Micro-commits:** Programar y realizar commits inmediatamente después de completar cada pequeña subtarea o cambio atómico, garantizando un alto volumen de commits pequeños y claros.
- Never build after changes
- Do not run npm run build unless explicitly asked

## User Skills
- **branch-pr**: PR creation workflow for Agent Teams Lite. Triggers: When creating a pull request, opening a PR, or preparing changes for review.
- **go-testing**: Go testing patterns. Triggers: When writing Go tests, using teatest, or adding test coverage.
- **issue-creation**: Issue creation workflow. Triggers: When creating a GitHub issue, reporting a bug, or requesting a feature.
- **judgment-day**: Parallel adversarial review protocol. Triggers: When user says "judgment day", "review adversarial", "dual review", "doble review", "juzgar".
- **skill-creator**: Creates new AI agent skills. Triggers: When user asks to create a new skill, add agent instructions, or document patterns for AI.
- **ui-ux-pro-max**: UI/UX design intelligence. Triggers: button, navbar, modal, dashboard, landing page, responsive layout, glassmorphism, visual design.
